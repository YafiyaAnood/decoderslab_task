# Python To-Do List Application

## Project Overview
The Python To-Do List Application is a command-line task management program. It helps users organize their daily activities by adding, viewing, completing, and deleting tasks.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using JSON file storage
- Handle invalid user input

## Technologies Used
- Python 3
- JSON
- VS Code

## Concepts Practiced
- Variables and data types
- Lists and dictionaries
- Functions
- Loops and conditional statements
- Exception handling
- File handling and JSON
- Input validation

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the integrated terminal.
5. Run the command:

   python main.py

## Project Structure
- main.py: Application logic
- tasks.json: Saved task data
- README.md: Project documentation

## Learning Outcome
This project demonstrates fundamental Python programming concepts through a practical task management application.
